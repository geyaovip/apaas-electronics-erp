# 电子行业 ERP 实施与验收记录

初始验收日期：2026-09-25。本地 PostgreSQL 17、前端 4500、API 4501。以下为当时的验收快照。

- `pnpm build:erp` 通过，`pnpm test:erp` 在真实数据库上验证产品/供应商→采购确认→入库→库存→合同确认→出库→应收应付→分次收付款。库存不足、超额收款、重复出入库和销售私有数据越权均被拒。
- `pnpm local:seed` 已生成销售、采购、仓管、财务本地验收账号；`pnpm test:local-login` 已验证四个账号的登录、角色、登出和错误密码拒绝。
- 桌面浏览器完成产品创建、采购单创建/确认/入库并看到应付；390×844 手机视口检查登录与工作台。
- `pg_dump` 备份并还原到临时数据库后读取采购单、销售合同、库存流水表，随后删除临时数据库。当时本地计数为 3、2、5。
- 当时采用整单入库/出库；分批、退货、税务发票、复杂 BOM 和飞书/钉钉/企微连接尚未实现。

## 2026-09-27 增量验收

- 已实现采购按行分批入库、合同按行分批出库，记录每批单号、数量和库存流水；应收应付按实际批次金额累计。库存不足、超收超发、重复单号和旧版本请求均会拒绝，事务回滚不产生半批变更。
- 已实现盘点单与差异流水、产品低库存阈值、付款历史和同一账款重复参考号限制。
- `pnpm build:all` 与 `pnpm test:all` 通过；ERP 新增测试覆盖两批入库/出库、增量账款、盘点、重复参考号、权限与失败回滚，原 ERP 闭环测试仍通过。
- 浏览器检查过库存/盘点页、合同批次详情和财务付款历史。退货、税务发票、批次/序列号追溯、多仓库与三方平台连接仍未实现。
